# Happy Todo 

Happy Todo is a todo app I'm building to practice backend development. It lets users manage their tasks, with authentication and todo routes handled on the backend.

## Built With

- Node.js
- Express.js
- HTML
- CSS
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Boluwatife100/Happy-Todo-Application.git
cd Happy-Todo-Application
```

Install the dependencies:

```bash
npm install
```

Set up your `.env` file with the environment variables required by the app, then start the server using the script defined in `package.json`.

## What I'm Learning

I'm using this project to get more comfortable with building APIs, handling authentication, connecting to a database, and organizing backend code.
